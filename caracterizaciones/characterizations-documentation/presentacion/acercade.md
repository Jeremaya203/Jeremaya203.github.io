# Acerca de Caracterizaciones

Caracterizaciones Territoriales Digitales es una herramienta del Instituto Geográfico Agustín Codazzi (IGAC) orientada a facilitar el conocimiento integral del territorio colombiano.

La plataforma articula información geográfica, estadística y descriptiva para apoyar la consulta de las condiciones y dinámicas territoriales desde seis componentes temáticos:

* Límites municipales.
* Ordenamiento territorial.
* Contexto legal.
* Procesos biofísicos.
* Procesos de ocupación.
* Procesos socioeconómicos.
